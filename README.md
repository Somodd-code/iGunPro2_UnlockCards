CARD READER HELPER | SOMODD
===========================

EXISTING READER FEATURES
------------------------
- Load JSON/text files or paste a response.
- Display locked cards grouped by rarity.
- Search and sort cards.
- Watch live card captures from addon.py.

HOW TO USE
----------
1. Open the Google Play Games developer emulator and wait for Android.
2. Double-click Play.bat.
3. Follow the existing prompts to install the game and certificate in the
   emulator if needed.
4. The reader page opens and updates as card data is captured.
5. When finished, press Ctrl+C in the black window.
